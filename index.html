🔑 Fine-Grained Personal Access Token (FG-PAT) Configuration

Use a Fine-Grained Personal Access Token (starting with github_pat_) scoped strictly to your portfolio repository with Contents: Read and write. Your token is stored only in your local browser session/storage and is never committed into portfolio.json.

📋 Step-by-Step: Generate Fine-Grained Token
  1. Open GitHub Fine-Grained Personal Access Tokens.
  2. Set Token name (e.g. Naushifa Portfolio Sync) and choose an expiration duration.
  3. Under Repository access, select "Only select repositories" and choose your portfolio repository.
  4. Under Repository permissions:
    • Set Contents to Read and write (required to push portfolio.json).
    • Metadata will be set to Read-only automatically.
  5. Click Generate token, copy the string starting with github_pat_, and paste it in the field above!
