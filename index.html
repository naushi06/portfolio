🔗 GitHub Repository Connection

By providing a GitHub Personal Access Token (PAT) with repo permissions, this portal commits your updated portfolio.json directly to your repository using the official GitHub REST API. GitHub Pages then instantly broadcasts your updates worldwide!

📖 How It Works
  1. Create a Personal Access Token on GitHub with repo access:
    GitHub Settings → Developer Settings → Personal access tokens → Generate new token (classic).
  2. Enter your repository name (e.g. naushifarasheed/portfolio) and paste your token above.
  3. Whenever you edit your avatar, projects, skills, or positions, click "🚀 Push & Publish Live to World".
  4. The portal automatically commits and updates portfolio.json in your repository. Everyone visiting your site will see the updated portfolio immediately!
